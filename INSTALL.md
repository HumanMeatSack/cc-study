# Install CC Study 1.0.1 beta

Requires Android 12 or newer. This is an Android APK and does not run on iPhone.

1. Open https://github.com/HumanMeatSack/cc-study/releases/download/v1.0.1-beta.1/CC-Study-1.0.1.apk on the Android phone.
2. Wait for the download to finish, then open `CC-Study-1.0.1.apk` from the browser's Downloads.
3. If Android asks, allow installation from the browser used for this download.
4. Choose Install, then Open.
5. Tap Start endless practice, select one answer, and tap Check answer. Correct answers show Correct!; press Next question when ready. Wrong answers show the correct choice and a short explanation; Learn more expands details and Show less collapses them. Press Next question to continue. Neither outcome advances automatically.

The app works offline after installation. Your progress and current question remain saved when you close and reopen it; choose Continue your question. Review missed questions returns items whose latest answer was wrong.

## Updates and data

Install future APKs with the same package and signing identity over the existing app. Do not uninstall first to apply an update: uninstalling deletes saved progress. If Android reports a signing conflict, stop and report it instead of clearing data.

The beta uses package `dev.joe.ccstudy`, version 1.0.1 / code 2 and an Android debug signing certificate. It is an early test distribution, not a Google Play production release.
